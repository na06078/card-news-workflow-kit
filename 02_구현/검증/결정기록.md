# 결정 기록 — I2 연결 단계

원본 사용자 결정/기술 방향은 [현재상태](../../📋%20현재상태.md)와 [CN-1](../../01_기술설계/📖%20인터페이스%20계약.md)이 기준입니다. I2에서 스택·외부 계약·과금 조건을 새로 정하지 않았습니다.

1. **실제 모듈 연결**: F1 App/default HTTP client → B1 Express/SQLite → W1 별도 worker → G1 실제 factories/R1 renderCard·buildExport. 공용 bootstrap은 모든 생산 카드 완료 후 순차 변경했습니다. src/shared와 생산 모듈은 읽기 전용으로 유지했습니다.
2. **정상 기본값**: server·worker는 real Store, 실제 G1 factory, LivePermission 전부 false. 서버 시작/import/build에서 SDK accountInfo/initialization/query/login/status/warmup/refresh/agy 호출 없음. AUTH_MODE_UNKNOWN을 합성 결과로 대체하지 않습니다. agy는 `command -v`와 디렉터리 목록으로 확인한 기존 `C:\Users\YH\AppData\Local\agy\bin\agy.EXE` 위치를 연결했으나 실행/버전/auth는 검증하지 않았습니다.
3. **시험만 명시 주입**: `tests/integration/fixtures/I2`의 합성 Claude 결과·질문과 G1 createOfflineAgyAdapter의 fake 실행 결과만 사용. fake가 만든 단색 PNG는 실제 파일 검증을 통과하며 real spawn은 없습니다. 이 fixture 자체가 만든 픽셀에 한해서 이용 조건 확인을 표시하고, 실제 agy 약관 확인과 구분했습니다. 정상 진입점은 fixture를 import하지 않습니다.
4. **출처 정직성**: example.org/I2-synthetic URL, 날짜 null, SYNTHETIC/실제 원문 미검증 고지. opened/accessedAt/근거/claim은 실제 웹 접근 기록이 아닌 대역 출력임을 명시합니다. 시험 생성 시각을 뉴스 게시일/사건일로 대입하지 않습니다.
5. **수명과 보관**: dev는 별도 HTTP·worker 자식을 소유하고 IPC 종료/exit를 기다립니다. 주입 Store·agy는 조립자가 close/dispose합니다. 기본 사용자 상태는 실행데이터/앱, 시험은 실행데이터/I2/<UUID>. I1/타 카드의 DB·증거는 다시 쓰지 않습니다. 테스트용 `--data-dir=<절대경로>`는 서버·worker·dev에서 같은 DB 위치를 명시하는 인자이며 공급자 모드를 전환하지 않습니다.
6. **복구 증거 분리**: HTTP/worker OS 프로세스의 실제 종료·재시작과, active callback에서 HTTP 객체만 재생성한 시험, 소실 lease를 미래 clock reconcile로 주입한 시험은 별개입니다. 실제 pending SDK 질문 resume나 실공급자 후손 정리를 성공으로 주장하지 않습니다.
7. **기본 크기/수정**: 사용자 선택대로 1080×1080 기본, 1080×1350 옵션 유지. I2는 정사각 흐름을 실행했고 세로·layout 실렌더는 R1/W1 선행 증거를 재사용했습니다. 공유 validator/승인 규칙을 테스트에 맞춰 완화하지 않습니다.
8. **인계 승인 경계**: 이번 완료는 로컬 구현 단계입니다. default 후속 확인, 독립 비판/리뷰와 실제 공급자 인수는 별도 승인 뒤 수행할 원래 요구입니다. 새 카드/에이전트/링크/Git 변경·커밋·배포·Hermes 설정/재시작은 하지 않았습니다.

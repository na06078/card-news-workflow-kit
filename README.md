# 카드뉴스 워크플로 제작 키트
원본 설계·검수 키트와 이를 바탕으로 구현한 로컬 웹앱(`02_구현/`)을 함께 보관하는 프로젝트입니다. 구현된 기능과 남은 문제를 구분하며, 전체 흐름 완료로 일괄 표시하지 않습니다.

**앱 버전: v0.3.0-dev.1 (개발판)** — 패키지·변경 기록·로컬 Git 태그를 같은 번호로 관리합니다. 화면의 ‘결과 v4’는 카드 결과물의 개정 번호이지 앱 버전이 아닙니다.

이번 기준점의7종 오프라인 검사는 **1,160 통과·17 실패·3 제외**입니다. 부분 복구의 실제 모델·UI 경로는 확인했지만 저장소 전체 검사가 통과한 정식 완료판은 아닙니다. 실패 범위와 검증 한계는 현재상태 문서를 확인하세요.

- 작업 파일의 미커밋 변경과 커밋된 버전 이력: [변경 기록](CHANGELOG.md)

검수 요약·직접 확인과 사실 재검증의 부분 복구를 지원합니다. 현재 대상은 **결과 v4 / 7장 ready**이며 배경 구도·원고·이미지는 그대로입니다. 아래 주소에서 새로고침하면 현재 저장 상태를 볼 수 있습니다.

http://127.0.0.1:5173/?project=43daccac-2d26-4db1-bdd7-3b0e6416cd55

- 작업 이력은 기본 접힘이며, 펼쳐도360px 안에서 스크롤합니다. 실제 브라우저에서100/1000/10000건과1440/390폭의 휠·마지막 조작 접근을 확인했습니다.
- 긴 근거·제약·검수 의견·원고 편집/전후 비교를 접고, 현재 상태·오류·가능한 행동·PNG는 유지합니다.
- 검수는 **짧은3문장**만 기본 표시합니다. 원문·보고서·AI 재검수 설정은 **‘검수 상세·재검수(선택)’**을 열어 봅니다. 모두 읽어야 다음으로 갈 수 있는 구조가 아닙니다.
- **‘카드 내용을 직접 확인했습니다. 체크하면 파일 준비로 이동합니다.’**를 새로 체크하면 현재 결과를 승인하고 PNG·ZIP 파일 준비로 넘어갑니다. 별도 최종 승인 버튼을 다시 누르지 않습니다. 이전 체크값이나 새로고침만으로는 승인하지 않습니다.
- 재검증이 실패해 저장 자료가 남아 있으면 **‘누락 부분 보완 후 계속’** 또는 **‘내용 검수부터 다시 시도’**로 해당 단계부터 이어갑니다. 기존 조사·이미지 생성을 전부 반복하지 않습니다. 추가 LLM 사용량은 발생하며 자동 재시도는 하지 않습니다. 원고·근거가 바뀌어 저장 지점이 오래됐으면 재개하지 않습니다.
- 현재 실패 건은 실제 부분 복구를 마쳐 **적용 전 제안**으로 저장돼 있습니다. **제작·검수 → 검수 상세·재검수(선택)**에서 확인하세요. ‘확인 불가’ 의견은 남아 있으며, 제안 저장이 원고 적용·사실 확인·최종 승인 성공을 뜻하지 않습니다.
- 요약·의역이 근거에 맞는지는 별도 LLM이 검토합니다. 코드는 문장 문자 일치를 사실 판정으로 삼지 않고, 출처 관측·인용·알려진 대상/참조·버전·승인·파일을 검사합니다. 보완 응답도 검사 전에 저장하며 원고를 자동으로 바꾸지 않습니다.
- PNG는 긴 URL 대신 매체명을 표시하고 조사 기준 날짜는 YYYY-MM-DD로 줄였습니다. 그림은 작은 상단 박스가 아니라 카드 전체 배경에 놓고, 그림 묶음 중심을 위쪽 30%로 올렸습니다. 하단 원고는 기존의 연속 그라디언트 위에 겹치며 불투명한 글상자·footer는 없습니다.
- 기존 배경·원고·출처·주장·검수 기록은 그대로 두고 `renderOnly:true`로 새 7PNG만 만들었습니다. 이전 v3를 포함한 옛PNG·이력·기존 52자산을 보존했고 새 이미지·모델/검색 호출은 0회입니다. 현재 그림 구도를 잘못 해석했던 v3의 상하 분할은 폐기하되 그 기록과 파일은 남겼습니다.

**AI 판정은 참고 경고이고, 사용자의 직접 확인이 승인 결정입니다.** 확인 불가·상충·검수 없음이어도 새 확인 체크로 진행할 수 있습니다. 기계 판정/원문 보고서는 그대로 보존하고 사용자 확인을 현재 결과 버전·시각·내용 해시로 별도 기록합니다. 카드/PNG 미완성·시각 검사 실패·진행 중 작업·미제출 초안·파일/사용조건 오류는 여전히 막습니다. 원본7장은 에이전트가 승인하지 않았으며 실제 승인은 사용자가 새로 체크할 때만 합니다. 추가 AI 검수는 상세에서 선택적으로 요청합니다.

기존3·7번 그림의 일부 하단 잘림과 별도 샘플의 지도 북쪽 잘림은 변경 전 원본에도 있습니다. 합성이 새로 자른 부분은 아니며 무단 재생성으로 교체하지 않았습니다. 일부 한글 어절 중간 줄바꿈과 더 긴 원고의 배치 한계도 남습니다. 상세 검증·제한·미커밋 상태는 현재상태 문서를 따릅니다.

## 원본 키트 사용법 — 제공 당시 설명

아래는 실행 앱이 없던 원본 키트의 사용 설명입니다. 현재 앱의 설치/기능 상태를 뜻하지 않으며, 기존 프로젝트 작업을 이어갈 때는 위 현재상태·실행안내를 먼저 읽습니다.

1. 압축을 풀고 폴더를 Claude Code 또는 OpenCode로 엽니다.
2. 아래 요청을 입력하고 AI의 질문에 답합니다.

> PRD.md를 읽고 카드뉴스 에이전트를 만들어 줘. 미정인 부분은 먼저 물어보고, 브라우저에서 후보를 고르고 질문에 답하는 흐름부터 보여 줘.

3. AI가 작성한 README에 따라 실행하고 안내받은 로컬 주소를 엽니다. 이 키트에는 실행 서버가 아직 없으므로 공통 실행 명령은 없습니다.
4. `AI 최신소식`을 입력하고 ACCEPTANCE.md를 확인합니다.
5. 만든 흐름을 자신의 주제로 바꾸고 달라져야 할 판단·도구·검수 조건을 PRD에 반영합니다.

실행 엔진은 Claude Agent SDK, Claude CLI, OpenCode CLI 중 하나로 시작합니다. 이미지 생성에는 공식 Antigravity CLI `agy`를 사용합니다. 설치되어 있다는 것과 실제 로그인·검색·이미지 생성 권한이 있다는 것은 다릅니다. 사용할 계정에서 각 기능을 확인하세요.

공식 사용법과 카드 형식 레퍼런스는 REFERENCES.md를 참고하세요.
